## 💡 Quick Reference

### Core Growth Metrics
- **CAC** (Customer Acquisition Cost) - How much to acquire one customer
- **LTV** (Lifetime Value) - Total value from one customer
- **Retention** - How many users stay engaged
- **Churn** - How many users leave
- **Unit Economics** - CAC vs LTV ratio

### Growth Frameworks
- **AARRR** (Acquisition, Activation, Retention, Revenue, Referral)
- **Pirate Metrics** - North Star metric approach
- **Jobs to be Done** - User-centric growth lens
