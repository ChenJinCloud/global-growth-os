## 📚 Research Process Overview

```
Define Question
    ↓
Identify Sources (use high-quality-sources.md)
    ↓
Choose Method (use research-methodology.md)
    ↓
Collect Data (use templates in deep-dive-templates/)
    ↓
Analyze & Synthesize
    ↓
Make Decision
```
