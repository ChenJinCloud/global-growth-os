# 📚 Growth OS Documentation

Complete knowledge base for global growth professionals. Organized in three layers of increasing depth.

## 📂 Structure

### [01-foundation/](./01-foundation/) - Roles, Tools & Fundamentals

👉 **Use these to understand growth problems deeply.**

👉 **Reference these for deeper learning.**
