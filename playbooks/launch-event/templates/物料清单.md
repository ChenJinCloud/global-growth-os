# 物料清单 · 模板

> T-3 开始备料。打印出来，装箱时逐项打勾。

## 设备

- [ ] 笔记本电脑（满电 + 充电器）
- [ ] 转接头（USB-C → HDMI / VGA），至少两种
- [ ] 翻页笔（含备用电池）
- [ ] 手机支架（录现场用）
- [ ] 录音设备或手机录音（提前测音量）
- [ ] 移动电源
- [ ] 插排（场地插座常常不够）

## 现场物料

- [ ] 签到表（打印版 + 签字笔）
- [ ] 姓名贴 / 桌牌
- [ ] 便签纸（每组一本）
- [ ] 马克笔（每组两支，粗头）
- [ ] 组纸 / 大白纸（每组一张）
- [ ] 举牌道具（🤯 / ✅ / ❌ 三种，可打印 A5 卡片）
- [ ] 胶带 / 图钉（贴组纸上墙）
- [ ] 二维码牌（报名 / 加群 / 关注，立在入口）

## 演示准备

- [ ] 演示用账号已登录，状态干净
- [ ] 预跑录屏已导出，本地可播（网络挂了能放）
- [ ] 问题池已整理成 3–5 类，打印一份给主持人
- [ ] 待建清单页面已打开（现场记 ❌ 用）

## 收尾

- [ ] 垃圾袋
- [ ] 物料回收清单（照这份逐项清点）

## 装箱前最后确认

- [ ] 投影接上自己的电脑能亮
- [ ] 手机能连上场地网络
- [ ] 录音设备有电、有空间
