# 宣发清单与文案模板

> T-7 开始用。目标不是"发得多"，是"来的人对"。

## 一、发布节奏

| 时间 | 动作 | 渠道 |
| --- | --- | --- |
| T-7 | 第一轮：活动介绍 + 报名 | 公众号 + 私域 + 社群 |
| T-4 | 第二轮：讲什么 / 谁会来 / 为什么值得来 | 即刻 / X / 小红书 |
| T-2 | 第三轮：最后的提醒（剩余名额） | 私域 + 社群 |
| T-1 | 提醒：时间地点、要带什么 | 活动群 |
| T+0 当晚 | 现场实况（照片 / 一句话结论） | 即刻 / 朋友圈 |
| T+2 | 复盘：来了多少 / 采纳了什么 / 下次 | 公众号 |

**只选 2–3 个渠道做透，不要六个渠道都发一半。**

## 二、渠道口径（同一件事，不同说法）

| 渠道 | 语气 | 长度 |
| --- | --- | --- |
| 公众号 | 完整叙事，能扩成长文 | 长 |
| 即刻 | 一句话钩子 + 细节 | 中 |
| X | 单条，结论先行 | 短 |
| 小红书 | 感受 + 具体场景 | 中 |
| GitHub | 公告口吻，给已有用户 | 短 |
| 朋友圈 / 私域 | 熟人语气，带个人动机 | 中 |

## 三、文案模板

### A. 公众号（活动介绍）

```
标题候选：
1. {{活动名}}：{{一句话价值}}
2. 我们做了一场 {{活动形式}}，想请 {{目标人群}} 来

正文结构：
1. 我为什么办这场（个人动机，一到两句）
2. 现在做到哪一步了（诚实，包括没做到的）
3. 现场会发生什么（按流程总表说三段）
4. 适合谁来 / 不适合谁来
5. 时间地点、报名方式
```

### B. 即刻

```
{{一句话钩子：最有反差的那个事实}}

{{两到三句具体：现场会做什么、你能拿走什么}}

{{时间地点}}

报名：{{链接}}
```

### C. X（中文单条）

```
{{结论先行的一句话}}

{{一个具体数字或事实支撑}}

{{时间 + 地点 + 报名链接}}
```

### D. 小红书

```
{{场景开头：某个具体的人会遇到的问题}}

我们做了一场 {{活动形式}}，专门解决这个。

现场你会：
· {{第一件事}}
· {{第二件事}}
· {{第三件事}}

{{时间地点}}
```

### E. GitHub 公告（已有用户）

```
## {{活动名}}

我们会在 {{日期}} 办一场线下活动，主题是 {{主题}}。

现场包含：
- {{环节 1}}
- {{环节 2}}

如果你在用这个项目，欢迎来当面提问题——现场收集的意见会直接进路线图。

时间 / 地点 / 报名：{{链接}}
```

### F. 朋友圈 / 私域

```
{{熟人语气：我最近在做 X，遇到 Y，所以想组个局}}

{{时间地点，一句话}}

来的话回我一个 🙋
```

## 四、素材缺口自查

发之前确认这几样齐不齐：

- [ ] 一句话说清"这是什么"
- [ ] 一张能当封面的图（真人出镜比产品截图转化高）
- [ ] 时间、地点、时长
- [ ] 报名链接（能直接打开）
- [ ] 适合谁 / 不适合谁（写明"不适合"反而更多人报名）
