# 完整研究表

> 只有当你需要解释**整个爆发期**、而不是单条帖子的效果时才用这三张表。先跑完六张卡，再扩大到这里的规模。

## 采集顺序与停止条件

```
根帖 → 一级互动 → 有后续互动的引用帖
```

开始前先写下三件事，否则样本会失控：

| 项 | 你的设定 |
| --- | --- |
| 追踪深度（追几层） | |
| 筛选标准（什么算进样本） | |
| 停止条件（什么时候收手） | |

**必须保留负面反馈和普通内容**，不能只收高互动样本。

## 四类传播问题（分析框架）

填写顺序：先记录内容怎样表达 → 再观察评论与引用 → 分别归纳情绪和分享动机 → 最后检验前后变化是否支持候选引爆点。

| 分析项 | 要回答的问题 | 填写字段 |
| --- | --- | --- |
| **内容切入点** | 内容通过什么角度抓住目标用户？ | 目标人群 / 原有痛点 / 首句或开场 / 价值承诺 / 差异化 / 演示或证据形式 / 行动引导 / 原始证据编号 |
| **传播点（转发点）** | 受众为什么愿意分享？分享时增加了什么？ | 可分享信息单元 / 实际引用表达 / 实用价值或身份表达 / 激励条件 / 关联分享行为 / 依据 / 待核假设 |
| **情绪点** | 用户在评论或引用中表达了什么情绪？ | 具体表达 / 情绪标签 / 触发内容 / 用户角色 / 正负向 / 对应行为 / 反例 / 推断限制 |
| **候选引爆点** | 什么节点之后，传播速度、人群或议题出现明显变化？ | 节点及时间 / 前后指标 / 新增人群与议题 / 上下游证据 / 同期其他事件 / 替代解释 / 确认状态 |

先填可见的文字、行为或数据，再写解释。**没有观察到的变化填"未观察到"。**

## 表 1 · 根帖表

| 字段组 | 记录内容 | 填写要求 |
| --- | --- | --- |
| 定位与来源 | 证据编号、帖子 ID 或链接、发布时间与时区、采集时间 | 一个原帖一个编号；发布时间与采集时间分别填 |
| 作者与关系 | 公开账号、角色或所属关系、分类依据、粉丝与关注数 | 只记录与研究相关的公开身份；关系不明单列 |
| 内容与媒介 | 正文、图片/视频/链接、补充线程 | 正文与附件分开保留，记录可访问范围 |
| 数据快照 | 曝光、点赞、评论、纯转发、引用转发、收藏、缺失字段 | 保留采集时的数据；**缺失值不填零** |

## 表 2 · 互动表

| 字段组 | 记录内容 | 填写要求 |
| --- | --- | --- |

## 交付报告结构

扩大研究后按这个结构整理：

```
1. 研究问题与要决定的事（卡 1）
2. 观察窗口与变化证据（卡 2）
3. 样本与采集方法（追踪深度 / 筛选标准 / 停止条件）
4. 根帖与互动记录（表 1、表 2）
5. 四类传播分析（内容切入点 / 传播点 / 情绪点 / 候选引爆点）
6. 发现与限制（哪些是观察，哪些是解释，哪些未确认）
7. 验证计划（卡 6 的行动卡）
```

第 6 节必须能回答：**如果我的解释是错的，会看到什么反证？**
