# 竞品爆发期研究 · 检查清单

## 开始前

- [ ] 能说出"研究完成后我要决定哪一件事"（写不出就别开始）
- [ ] 选定了**一个**参考产品，不是三个
- [ ] 知道自己的产品在什么条件下能展示同样真实的价值
- [ ] 准备好：参考产品的公开主页与账号、至少一条发布内容、可得的流量或讨论趋势

## 采集时

- [ ] 根帖链接能直接打开
- [ ] **发布时间**和**数据采集时间**分开记录
- [ ] 每条证据有编号（E01、E02…），后面所有判断回指编号
- [ ] 拿不到的字段写"未取得"或"未知"，**不填零、不留空**
- [ ] 截图或存档保留了原帖可访问范围
- [ ] 区分了评论 / 纯转发 / 引用转发（引用才有新增文案）

## 分析时

- [ ] **观察事实**和**可能解释**分两行写，不混
- [ ] 每条发现都标了证据编号
- [ ] 每条发现都写了"未确认部分"
- [ ] 情绪标签有原文依据，没有依据就不贴标签
- [ ] 候选引爆点写了替代解释（同期还有什么事件也可能导致变化）
- [ ] 没有用传播数据推断转化

## 交付前

- [ ] 六张卡在同一份记录里（最小交付）
- [ ] 别人能顺着编号找到每一条原文
- [ ] 行动卡有：具体动作、负责人、素材、时间、验证方式、判断标准
- [ ] 验证标准是**事前约定**的，不是事后解释
- [ ] 无法确认的判断仍标为假设

## 扩大研究时额外检查

- [ ] 写下了追踪深度、筛选标准、停止条件
- [ ] 补了一轮**没有直接转推官方帖**的独立讨论
- [ ] 保留了负面反馈和普通内容
- [ ] 其他渠道、产品更新、后续运营放进了同一条时间线
- [ ] 交付报告第 6 节能回答"如果我的解释是错的，会看到什么反证"

## 常见卡点

| 卡在哪 | 怎么办 |
| --- | --- |
| 找不到引用转发 | 改用一条评论，注明它反映的是"回应"而非"扩散" |
| 拿不到互动数据 | 写"未取得"，用可见的评论内容做判断 |
| 样本太少不敢下结论 | 这是对的。一个样本只能产出假设，不能产出结论 |
| 越追越多收不住 | 回到卡 1：你的研究问题需要那么多吗？ |
