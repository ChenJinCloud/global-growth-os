## 🎯 Case Study Format

Each case study includes:

```markdown
# Case: [Title]

## 📊 Context
- Company/Product: [...]
- Market: [...]
- Stage: [Early/Growth/Scale]
- Challenge: [...]

## 🔍 Methodology Used
- Research approach: [...]
- Key frameworks: [...]
- Tools applied: [toolkit references]

## 🛠️ Tools & Tactics
- Tool 1: [How it was used]
- Tool 2: [How it was used]
- [See toolkit/ for tool setup]

## 📈 Results
- Key metrics: [Before/After]
- Timeline: [How long it took]
- Success factors: [What worked]

## 💡 Key Learnings
- Learning 1: [...]
- Learning 2: [...]
- Replicable insights: [...]

## ⚠️ Challenges & Mistakes
- What didn't work: [...]
- Why: [...]
- How to avoid: [...]

## 🔗 References
- Related docs: [links]
- Tools used: [links]
```

## 🤝 Contributing Your Case Study

Have a growth experiment or case you'd like to share?

**Steps:**
1. Create a new file: `case-XX-[your-case].md`
2. Follow the template above
3. Include specific metrics and learnings
4. Submit a [Pull Request](../../pulls)
5. Discuss and refine with the community

**What makes a great case study:**
- ✅ Specific metrics (numbers, not vague)
- ✅ Clear before/after comparison
- ✅ Honest about failures
- ✅ Replicable insights others can apply
- ✅ Links to methodologies and tools used

## 📚 How to Learn from Cases

### "I'm struggling with [specific growth problem]"
→ Search cases by keyword  
→ Find the most relevant case study  
→ Review methodology & tools used  
→ Apply learnings to your context

### "I want to understand how [specific tool] is used"
→ Search toolkit usage across cases  
→ See different applications  
→ Learn variations and customizations

### "I'm validating a growth hypothesis"
→ Find similar cases  
→ Understand what worked/didn't  
→ Design experiments based on learnings
