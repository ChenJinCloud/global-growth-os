# 🌍 Global Growth OS

An open operating system for global growth research, experiments, workflows, and reusable tools. **Build in Public** from 9/10 to 9/24, with a live demo on 9/24 evening.

## 🎯 Mission

From zero to one: Through 14 days of **build in public**, we construct an operating system that turns global growth knowledge, research methodology, and toolkits into a knowledge base anyone can ask.

## 📐 Four-Layer Architecture

### 1️⃣ Foundation: Roles & Fundamentals
- Roles and responsibilities for growth professionals
- Industry tools, platforms & essentials
- Fundamental knowledge base

### 2️⃣ Input: Deep Dive Methodology & Sources
- Personal research methodology
- High-quality sources for growth
- Customized deep-dive content templates

### 3️⃣ Output: Growth Toolkit
- Reusable tools, templates, scripts
- Workflows solving real problems
- Integration guides & tutorials

### 4️⃣ Iteration: Feedback & Community
- Live community events
- Real-time feedback collection
- v0.2 co-creation with community

## 📁 Repository Structure

| Path | Responsibility |
|---|---|
| `project.md` | Single project definition for the entire Global Growth OS |
| `ROADMAP.md` | Global roadmap and execution status |
| `architecture/` | Domain model, system layers, operating boundaries, and version design |
| `public-core/` | The open, reusable, collaborative Core and its build records |
| `experiments/` | Bounded experiments run to validate OS assumptions |
| `toolkit/` | Reusable tools, templates, scripts, and workflows |
| `docs/` | Foundational and methodological knowledge |
| `feedback/` | Community feedback and co-creation input |
| `outputs/` | Local working drafts — do **not** auto-enter Public Core |
| `archive/` | Superseded definitions, migration records, and historical snapshots |

## ⚖️ Authority Order

When there is a conflict, resolve in this order:

1. Current project scope and status: `project.md`, `ROADMAP.md`
2. System concept and architecture: `architecture/`
3. A single experiment: its own `experiments/<experiment>/project.md`
4. Current public repo state: verify live against `ChenJinCloud/global-growth-os`
5. `archive/` and `public-core/history/` are historical evidence only — they do not define current state
