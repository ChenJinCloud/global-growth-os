# Global Growth OS

Global Growth OS organizes global growth decisions and execution into a reusable system. Public resources include knowledge, generic architecture, and experiment materials; team missions run in private instances.

## Start here

- [Feishu knowledge base](https://my.feishu.cn/wiki/Kg2qw1cJCiYOOMkPFVocqbZXn9f): read content by practical task.
- [Public resource index](public-core/content-index.md): find methods, workflows, and cases.
- [Project](project.md), [roadmap](ROADMAP.md), and [architecture](architecture/global-growth-os-concept-and-architecture-v0.1.md): check scope and progress.
- [Public boundary](public-core/decisions/2026-10-09-public-boundary-and-version-policy.md) and [version definitions](public-core/VERSIONING.md): assess delivery claims.
