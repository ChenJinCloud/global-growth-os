# Global Growth OS

这是 Global Growth OS 在 `01-global-growth-system` 中的唯一完整项目目录。它管理 OS 的长期定义、架构、路线图、Public Core、运行机制、实验和历史记录；AWW'26 公测只是其中一次实验，不代表整个 OS。

## 先读什么

1. [`project.md`](project.md)：整个 OS 的定位、范围、权威边界和当前状态。
2. [`ROADMAP.md`](ROADMAP.md)：阶段、里程碑和当前缺口的唯一项目级执行入口。
3. [`architecture/global-growth-os-concept-and-architecture-v0.1.md`](architecture/global-growth-os-concept-and-architecture-v0.1.md)：完整概念架构与 v0.1 设计准源。
4. [`public-core/README.md`](public-core/README.md)：公开 GitHub Core 的职责和历史记录。
5. [`experiments/aww26-launch/project.md`](experiments/aww26-launch/project.md)：2026-09-10 至 10 月 1 日的 AWW'26 发布实验。
6. [`outputs/2026-09-24-growth-night-qa/README.md`](outputs/2026-09-24-growth-night-qa/README.md)：9/24 现场问题与实际回应的主入口（本地，未发布）。
7. [`outputs/2026-09-24-growth-night-topic-library/README.md`](outputs/2026-09-24-growth-night-topic-library/README.md)：此前按分享主题整理的次级参考，不作为现场问答索引。

## 目录职责

| 路径 | 职责 |
|---|---|
| `project.md` | 整个 Global Growth OS 的唯一项目定义 |
| `ROADMAP.md` | OS 全局路线图与执行状态 |
| `architecture/` | 领域模型、系统层级、运行边界和版本设计 |
| `public-core/` | 可公开、可复用、可协作的 Core 及其建设记录 |
| `experiments/` | 为验证 OS 假设而运行的有边界实验 |
| `outputs/` | 跨主题的本地整理与工作底稿；不自动进入 Public Core |
| `archive/` | 被替代的项目定义、迁移记录和历史快照 |

## 权威顺序

发生冲突时，按以下顺序处理：

1. 当前项目范围和状态：`project.md`、`ROADMAP.md`；
2. 系统概念与架构：`architecture/`；
3. 单次实验：对应 `experiments/<experiment>/project.md`；
4. 公开仓库当前状态：实时核验 `ChenJinCloud/global-growth-os`；
5. `archive/` 与 `public-core/history/` 只提供历史证据，不定义当前状态。
