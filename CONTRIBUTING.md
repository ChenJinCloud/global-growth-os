# Contributing to Global Growth OS

Thank you for your interest in contributing to Global Growth OS! We're building this in public and welcome all kinds of input.

## 📋 Ways to Contribute

### 1. 💡 Suggest Content
Have a topic you'd like us to deep-dive into? Or a growth challenge you're facing?

**How to contribute:**
- Open a [GitHub Issue](../../issues/new?template=content-suggestion.md) with the "content-suggestion" template
- Or fill our [Community Feedback Form](https://my.feishu.cn/share/base/shrcnEvCWvO9bLifOEOVlZzlyub)

**What we're looking for:**
- Growth challenges / pain points
- Topics for deep-dive research
- Tool recommendations
- Methodology improvements

### 2. 🛠️ Contribute Tools & Templates
Have a useful script, template, or workflow to share?

**How to contribute:**
1. Fork the repository
2. Create a feature branch: `git checkout -b feature/add-cohort-analysis-template`
3. Add your tool to the appropriate folder in [`toolkit/`](./toolkit/)
4. Include a `README.md` explaining how to use it
5. Submit a pull request with:
   - Description of the tool
   - Use case & problem it solves
   - How to use it
   - Any dependencies or setup required

**Tool categories:**
- `toolkit/excel-templates/` - Excel/Google Sheets templates
- `toolkit/python-scripts/` - Python analysis & visualization scripts
- `toolkit/sql-templates/` - SQL query templates
- `toolkit/notion-templates/` - Notion workspace templates

### 3. 🔬 Contribute Case Studies & Experiments
Share how you've applied growth methodologies or tools?

**How to contribute:**
1. Create a new markdown file in [`experiments/`](./experiments/)
2. Follow the case study template:
   ```markdown
   # Case: [Your Case Title]
   
   ## Context
   - Company/Product: [...]
   - Market: [...]
   - Challenge: [...]
   
   ## Approach
   - Methodology used: [...]
   - Tools applied: [...]
   - Timeline: [...]
   
   ## Results
   - Key metrics: [...]
   - Learnings: [...]
   - Replicable insights: [...]
   ```

### 4. 📚 Improve Documentation
Found a typo or want to improve existing docs?

**How to contribute:**
1. Edit the file directly or create a PR
2. Make your changes clear and well-explained
3. Submit the PR

### 5. 🗣️ Participate in Community Discussions
Join discussions about growth, methodologies, and tools.

- [GitHub Discussions](#) - Ask questions, share ideas
- [GitHub Issues](#) - Report bugs or suggest features
- [Feedback Form](#) - General feedback & feature requests

## 📏 Contribution Guidelines

### Code Style
- Python: Follow [PEP 8](https://www.python.org/dev/peps/pep-0008/)
- SQL: Use clear, commented queries with explanation
- Markdown: Use proper formatting, headers, and structure

### Documentation
Every contribution should include:
- Clear title and description
- Use case / problem statement
- How-to guide or examples
- Any dependencies or prerequisites
- Author name (optional but appreciated!)

### Commit Messages
- Use clear, descriptive commit messages
- Format: `[type]: description` (e.g., `[tool]: Add cohort analyzer script`)
- Types: `[tool]`, `[doc]`, `[case]`, `[fix]`, `[refactor]`

### Pull Request Process
1. Fork the repo and create a feature branch
2. Make your changes with clear commits
3. Test your changes (if applicable)
4. Submit a PR with:
   - Description of what you're adding
   - Why it's useful for the Growth OS
   - Any relevant links or references
5. Wait for review and feedback
6. Update based on feedback
7. Merge after approval

3. **Output** - Practical tools, templates, workflows

Your contributions help us build all four layers!
