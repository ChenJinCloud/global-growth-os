# Contributing to Global Growth OS

Suggest content or report broken links through [GitHub Issues](https://github.com/ChenJinCloud/global-growth-os/issues/new) or the [request form](https://my.feishu.cn/share/base/shrcnXy0zBFlHPCRBYWSclg4BBb). Proposed work follows the [current public boundary](public-core/decisions/2026-10-09-public-boundary-and-version-policy.md).

## Submit a contribution

1. Fork the repository and create a branch.
2. Add the actual document, tool, or case to the relevant directory.
3. Describe the problem, usage, dependencies, sources, and evidence of testing.
4. Open a [pull request](https://github.com/ChenJinCloud/global-growth-os/pulls) with the delivered scope and known gaps.

New tools must include their actual files and a usage guide. Toolkit categories are created when a contribution exists; this repository currently has no distributed Excel, Python, SQL, or Notion tool packages.

Case studies should state the context and baseline, explain the approach, and provide evidence for results. Separate observed outcomes from hypotheses and attribution claims. Get permission before including team information, and remove credentials and private data.

## Documentation and review

Use working links and preserve source attribution. Mark planned assets as planned. Claims of verification must name the tested scenario and evidence; claims of acceptance must meet the [version criteria](public-core/VERSIONING.md). Linked resources keep their own license and access terms.

Be respectful, avoid spam, and discuss disagreements with evidence. Maintainers review contributions before merging.
